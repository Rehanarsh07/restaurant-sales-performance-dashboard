# Restaurant Sales Performance Dashboard 📊

## About Project

This project analyzes restaurant sales data using Microsoft Excel to generate business insights and an interactive dashboard.

## Objective

To transform raw sales data into meaningful insights about revenue, customer behavior, and sales trends.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## Analysis Performed

- Revenue Performance Analysis
- Food Category Analysis
- Monthly Sales Trend Analysis
- Payment Method Analysis
- Customer Type Analysis

## Skills Demonstrated

- Advanced Excel
- Business Analytics
- Data Visualization
- Problem Solving
